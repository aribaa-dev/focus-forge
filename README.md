## FocusForge
A study-tracking app for students, built with Flutter and Firebase.
FocusForge helps students stay consistent by letting them plan their study tasks and record exactly how much time they spend studying. Everything is organised in one clean dashboard so progress is easy to see.

Features
Study time tracking: record how long you studied on each task or subject
Task management: add study tasks and keep them organised on your dashboard
Task history and details: look back at past sessions and see how your study time adds up
Personalised welcome: enter your name once and the app greets you each time
First-launch onboarding: a short intro shown only on the first run
Cloud storage: tasks and user data are stored in Cloud Firestore

Tech Stack
Area	Technology
Framework	Flutter (Dart)
Backend	Firebase (Cloud Firestore)
Local storage	SharedPreferences (onboarding state)
